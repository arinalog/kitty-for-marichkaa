ВСТАНОВЛЕННЯ НА GITHUB
1. Завантажте всі файли з цього архіву в корінь репозиторію kitty-for-marichka (не сам ZIP і не всю зовнішню папку).
2. index.html має замінити попередній index.html.
3. Натисніть Commit changes. Settings → Pages: main, /(root).
4. Дочекайтеся успішної публікації. Відкрийте сайт з інтернетом і дочекайтеся повідомлення «Гра готова до роботи без інтернету».
5. iPhone: Safari → Поділитися → На початковий екран → Додати. Android: Chrome → меню → Встановити застосунок / Додати на головний екран.
6. Запустіть гру через значок з інтернетом один раз. Потім можна грати без інтернету.
Прогрес зберігається локально. Не очищайте дані сайту. Safari й установлений застосунок можуть мати окремі збереження.
Для наступних оновлень sw.js змінюйте v1 на v2, v3 тощо.
